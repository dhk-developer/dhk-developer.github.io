The project

In summer 2022 I was a Computational Research Assistant at the University of Cambridge, through In2Research. The project applied random structure searching (AIRSS) to polyethylene. The idea is to generate lots of random but sensible starting structures, relax each one with a physical model, and see which low-energy arrangements keep turning up.

What I wrote

A Python package that:

  1. builds polymer chains with standard bond lengths and angles;
  2. makes a random periodic box and places chains in it without overlaps;
  3. rotates each chain randomly to widen the search;
  4. relaxes each structure with the AIREBO force field in LAMMPS, driven from Python through ASE, including the box shape under a set pressure;
  5. writes the results in formats that AIRSS tools and viewers like VESTA can read.

The optimised structures matched what's seen experimentally, and I presented the work as a poster at the In2Research summer conference.

Why it's here

It's the first real code I wrote, on Linux and a university computing cluster, inside someone else's research method. That meant understanding what they needed before writing anything.

What I'd change now

Add tests for the geometry code, pin the dependency versions, and separate generating structures from relaxing them so each part can be checked on its own.

Built with: Python, NumPy, ASE, LAMMPS, Linux / HPC.
