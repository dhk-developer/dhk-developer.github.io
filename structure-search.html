The project

In the summer of 2022 I spent three months as a Computational Research Assistant at the University of Cambridge, through the In2Research programme. The project applied a technique called random structure searching (AIRSS) to polyethylene. The idea is to generate a large number of random but physically sensible starting structures, relax each one with a model of the forces involved, and then see which low-energy arrangements keep turning up.

What I wrote

I wrote a Python package that builds polymer chains using standard bond lengths and angles, creates a random periodic box, and places the chains inside it without letting them overlap. Each chain is then rotated at random to widen the search. The package relaxes every structure with the AIREBO force field in LAMMPS, driven from Python through ASE, and allows the shape of the box to change under a set pressure. Finally it writes the results out in formats that the AIRSS tools and viewers like VESTA can read.

The optimised structures agreed with what's been observed experimentally, and I presented the work as a poster at the In2Research summer conference.

Why it's here

It was the first sizeable piece of code I'd written, and I wrote it on Linux and a university computing cluster, working within someone else's research method. Before I could write anything useful I had to understand what the researchers needed, which isn't so different from what I do now as a business analyst.

What I'd change now

I'd add tests for the geometry code, pin the versions of the libraries it depends on, and keep generating the structures separate from relaxing them, so that each part could be checked on its own.

Tools and languages used: Python, NumPy, ASE, LAMMPS, Linux / HPC.
