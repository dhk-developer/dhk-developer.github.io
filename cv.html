Profile

I build games and desktop tools in C#, and I'm looking for a junior software developer role. Since late 2025 I've been making Memora, a mobile rhythm game in Unity, together with the charting editor I use to build its levels, and I've written and released two Windows utilities in .NET 8. I also use Python and SQL for data work, including a pipeline from a rate-limited REST API into MySQL. Two years of consultancy work at Infotechtion and Xander Talent have made me comfortable working from requirements alongside engineers and non-technical stakeholders. I have an MSci in Chemistry from Imperial College London.

Projects

Memora, a mobile rhythm game and charting editor (Unity 6, C#)

Late 2025 – present
  • Designed the note model so that the data that decides a note's score (its beat, target and action) is stored separately from its keyframed animation, which means visual effects and camera movement can never change how a note is judged.
  • Derived all gameplay timing from the audio DSP clock with scheduled playback, sampling every pose from the current beat instead of integrating per frame, and wrote a four-tap latency calibration that rejects inconsistent taps.
  • Built notes that aim at other notes or at moving points, with every target computed as a pure function of chart and beat so that the game and the editor produce identical results when seeking in either direction.
  • Built a charting editor in Unity that previews the gamefield at any beat, using evaluators shared with the game, an interval tree over object lifetimes and latest-request-wins seeking.
  • Profiled an editor slowdown and cut the average repaint on the largest chart from about 120 ms to 15 ms, confirming no change in output with 18,125 automated comparisons and pixel-identical screenshots.

DesktopIdle, a Windows tray utility (C#, .NET 8, Win32)

2026
  • Clears the desktop after a period of inactivity and restores it when the user returns, using Win32 idle detection, window and taskbar control and the Windows media-session API, with a grace period so the app's own cursor movement isn't mistaken for the user coming back.

Touch FX, a click-effect overlay (C#, WPF)

2026
  • A transparent, click-through overlay across every monitor that detects clicks with a low-level mouse hook and only subscribes to rendering while an effect is on screen.

League of Legends data study (Python, SQL, Riot Games API)

2024
