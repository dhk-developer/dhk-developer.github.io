Why I made it

Windows has Show desktop, but only when you ask for it. I wanted my desktop to clear itself when I walk away, so the wallpaper shows like a quiet screensaver, and then put every window back exactly where it was when I return. It shouldn't do any of that in the middle of a game, a full-screen app or a video I'm watching.

It's a small tray app. It lives on GitHub with two tagged releases, and each is a single .exe that doesn't need .NET installed.

Deciding what "idle" means

Windows will tell you how long it's been since the last keypress or mouse movement, but that isn't the whole answer:

  • a film playing full screen means no input, but I'm still watching;
  • a YouTube tab only matters while it's playing, not while it's paused;
  • games should never trigger it, and some windows, like a music player, should stay visible when everything else is minimised.

So before the idle timer counts, the app checks whether an excluded app is in front, whether the front window fills its monitor, and whether media is actually playing. For browsers it reads the window title to spot a video site, then asks the Windows media-session API whether anything is playing. That check is slow, so it's cached.

The bug where it woke itself up

To clear the desktop, the app moves the cursor away from the taskbar and minimises windows. Both of those count as input, and input is exactly what ends idle mode. In the first release it would sometimes exit the moment it started.

Looking back, this was a requirements mistake before it was a code mistake. "Exit when the user moves" should have been "exit when the user moves, not when we move the cursor". Once I wrote it that way, the fix in v1.0.1 was clear:

  1. Ignore input for a short grace period right after clearing the desktop.
  2. Remember where the cursor ended up.
  3. Only wake up if the cursor moves at least 100 pixels from there, so a knock on the desk doesn't count.

Smaller decisions

  • Hiding the cursor. Rather than changing the system cursor, which would stay changed if the app crashed, I put an almost invisible full-screen window on top that has a blank cursor. If the app dies, the window goes with it.
  • The taskbar. It turns on taskbar auto-hide while the desktop is clear, but saves your setting first and puts it back afterwards.
  • Restoring. Windows come back in their original order with a tiny delay between each, so they don't all redraw at once.
  • Settings are a plain JSON file, and every value is clamped to a safe minimum when it's loaded.

What I'd add next

A small test harness for the idle state machine, so the grace-period logic can be tested without a real desktop.

Built with: C#, .NET 8, WinForms, Win32 P/Invoke, WinRT media sessions, JSON settings.
